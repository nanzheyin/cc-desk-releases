# Vibework CC Desk Releases

由 [nanzheyin](https://github.com/nanzheyin) 维护的 CC Desk 桌面安装包发布仓库。

本仓库仅发布桌面安装包、版本说明和校验清单；应用源码在独立私有仓库维护，不上传到这里。

下载入口：[Releases](https://github.com/nanzheyin/cc-desk-releases/releases)。目前尚未发布桌面安装包。

每个正式版本使用 `vX.Y.Z` 标签，附带 `CC-Desk-Vibework-Setup-X.Y.Z-x64.exe`、`release.json` 和 `SHA256SUMS`。客户端检查发布清单并验证安装包 SHA256 后才允许安装。草稿和预发布版本不作为正式更新。

上游基础项目：[sun168567/cc-desk-tunnel](https://github.com/sun168567/cc-desk-tunnel)。感谢原作者和贡献者；安装包及其第三方组件保留各自的许可与声明。
